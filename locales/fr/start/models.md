# Modèles et fichiers RVC

Un modèle RVC modifie le caractère vocal d'un enregistrement existant. Commencez par un enregistrement vocal isolé afin que l'audio de fond n'interfère pas avec la conversion.

 | Fichier | Objectif |
| --- | --- |
 | `.pth` | Modèle de point de contrôle utilisé pour convertir la voix. |
 | `.index` | Index de récupération facultatif. Utilisez l'index de correspondance fourni avec le modèle. |

Si le résultat ne semble pas naturel, essayez une entrée propre et comparez avec l'index désactivé. Ajustez le pitch progressivement et rejouez le même extrait pour chaque comparaison.
