# Documentation Ilaria RVC

Vous pouvez aussi utiliser Ilaria RVC sur Kaggle avec son GPU distant, même si votre ordinateur n’a pas de GPU NVIDIA. [Ilaria RVC on Kaggle](ilaria-rvc/kaggle.md)

<div class="docs-welcome">

Ilaria RVC est une application Windows permettant de convertir des enregistrements et de former des modèles vocaux. Son interface s'ouvre dans un navigateur et le moteur de conversion s'exécute sur votre ordinateur. Le package Windows est conçu pour les GPU NVIDIA.

[Télécharger pour Windows](https://huggingface.co/TheStinger/Ilaria_RVC) · [Parcourir les démos vocales](https://ilariarvc.shop/en/demos/) · [Lire le journal des modifications](ilaria-rvc/version-history.md)

</div>
