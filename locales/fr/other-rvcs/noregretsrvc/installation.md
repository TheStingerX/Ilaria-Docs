# NoRegretsRVC · Installation

NoRegretsRVC Beta 0.0 prépare des flux Applio via une interface web et génère des notebooks.

[GitHub](https://github.com/HunterThatsMe/NoRegretsRVC) · [Changelog](https://github.com/HunterThatsMe/NoRegretsRVC/blob/main/CHANGELOG.md)

## Installation

Installez Node.js 22 ou plus récent avec npm. Exécutez les commandes dans le dossier du projet. Ouvrez l’adresse du terminal et laissez le processus ouvert.

~~~bash
git clone https://github.com/HunterThatsMe/NoRegretsRVC.git
cd NoRegretsRVC
node --version
npm install
npm run dev
~~~
