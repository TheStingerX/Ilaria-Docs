# VoiceStudio · Installation

[VoiceStudio v0.5.8](https://github.com/debpalash/VoiceStudio/releases/tag/v0.5.8) · [GitHub](https://github.com/debpalash/VoiceStudio)

## Préparation

Choisissez le paquet 0.5.8 adapté au système. Sous Windows x64, prenez l’EXE x64. Sur Apple Silicon, prenez le DMG arm64. Sous Linux x64, choisissez DEB ou AppImage. Sous Windows ARM, le backend x64 peut tourner en émulation. Sur Mac Intel, examinez le backend distant.

## Premier essai

Attendez la préparation du backend. Dans le gestionnaire de modèles, installez le moteur de votre premier essai et vérifiez l’espace disponible. Générez une phrase courte.
