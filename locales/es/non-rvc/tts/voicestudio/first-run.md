# VoiceStudio · Primera síntesis

[VoiceStudio v0.5.8 · Primera síntesis](https://github.com/debpalash/VoiceStudio/blob/v0.5.8/README.md)

## Preparación

Elige un motor instalado, una voz y un idioma compatible. Escribe una frase, genera y escucha hasta el final. Guarda el audio cuando la prueba esté completa.

## Primera prueba

Mantén texto y voz fijos cuando pruebes un ajuste. Escribe las abreviaturas y números con palabras si la pronunciación falla.

## Comprobación paso a paso

1. Genera dos frases con una pausa.
2. Escucha inicio, final y nombres.
3. Corrige un elemento cada vez y vuelve a generar.
4. Abre el WAV con un reproductor independiente.
