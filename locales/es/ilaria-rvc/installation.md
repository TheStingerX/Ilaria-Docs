# Instalación y actualizaciones

## Instalar el paquete de Windows

Descargue la compilación de NVIDIA compatible desde [Hugging Face](https://huggingface.co/TheStinger/Ilaria_RVC). Extraiga todo el archivo en una carpeta local grabable y ejecute `ILARIA_RVC.bat` allí. El iniciador y el tiempo de ejecución incluido deben permanecer juntos. Si no se abre ninguna pestaña del navegador, intente con `http://127.0.0.1:6969` en la misma PC.

## Actualizar una instalación existente

Abra **Otro → Actualizar Ilaria RVC**. Consulte las notas de la versión, finalice los trabajos activos y haga una copia de seguridad de los modelos, conjuntos de datos y el estado del experimento antes de elegir **Descargar y reiniciar**. Mantenga el iniciador abierto durante la actualización. Si falla, observe el primer error y comience con `ILARIA_RVC_LOGS.bat` para obtener una consola de diagnóstico.
