# Modelos y archivos RVC

Un modelo RVC cambia el carácter vocal de una grabación existente. Comience con una grabación de voz aislada para que el audio de fondo no interfiera con la conversión.

 | Archivo | Propósito |
| --- | --- |
 | `.pth` | Punto de control del modelo utilizado para convertir la voz. |
 | `.index` | Índice de recuperación opcional. Utilice el índice correspondiente suministrado con el modelo. |

Si el resultado no parece natural, pruebe con una entrada limpia y compárelo con el índice deshabilitado. Ajuste el tono gradualmente y reproduzca el mismo extracto para cada comparación.
