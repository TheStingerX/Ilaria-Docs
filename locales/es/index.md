# Documentación de Ilaria RVC

También puedes usar Ilaria RVC en Kaggle con su GPU remota, incluso si tu ordenador no tiene una GPU NVIDIA. [Ilaria RVC on Kaggle](ilaria-rvc/kaggle.md)

<div class="docs-welcome">

Ilaria RVC es una aplicación de Windows para convertir grabaciones y entrenar modelos de voz. Su interfaz se abre en un navegador y el motor de conversión se ejecuta en su computadora. El paquete de Windows está diseñado para GPU NVIDIA.

[Descargar para Windows](https://huggingface.co/TheStinger/Ilaria_RVC) · [Explorar demostraciones de voz](https://ilariarvc.shop/en/demos/) · [Leer el registro de cambios](ilaria-rvc/version-history.md)

</div>
