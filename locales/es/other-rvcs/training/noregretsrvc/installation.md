# NoRegretsRVC · Instalación

NoRegretsRVC Beta 0.0 prepara flujos de Applio desde una interfaz web y genera notebooks.

[GitHub](https://github.com/HunterThatsMe/NoRegretsRVC) · [Changelog](https://github.com/HunterThatsMe/NoRegretsRVC/blob/main/CHANGELOG.md)

## Instalación

Instala Node.js 22 o posterior con npm. Ejecuta los comandos desde la carpeta del proyecto. Abre la URL de la terminal y deja el proceso activo.

~~~bash
git clone https://github.com/HunterThatsMe/NoRegretsRVC.git
cd NoRegretsRVC
node --version
npm install
npm run dev
~~~
