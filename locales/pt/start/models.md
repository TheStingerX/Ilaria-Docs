# Modelos e arquivos RVC

Um modelo RVC altera o caráter vocal de uma gravação existente. Comece com uma gravação de voz isolada para que o áudio de fundo não interfira na conversão.

 | Arquivo | Finalidade |
| --- | --- |
 | `.pth` | Ponto de verificação do modelo usado para converter a voz. |
 | `.index` | Índice de recuperação opcional. Use o índice correspondente fornecido com o modelo. |

Se o resultado não parecer natural, tente uma entrada limpa e compare com o índice desabilitado. Ajuste o tom gradualmente e reproduza o mesmo trecho para cada comparação.
