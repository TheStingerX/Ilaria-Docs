# Verificador de conjunto de dados e analisador de áudio

[Descarregar o Ilaria RVC 2.4.0 para Windows (ZIP)](https://huggingface.co/TheStinger/Ilaria_RVC/resolve/main/releases/2.4.0/ILARIA_RVC-2.4.0.zip?download=true)

## Revise as gravações originais

Use o **Verificador de conjunto de dados** para localizar possíveis cortes, pausas longas, arquivos ilegíveis e níveis ativos inconsistentes. Ouça os intervalos sinalizados antes de editar. Preserve pausas intencionais e uma entrega silenciosa quando pertencem à voz pretendida.

## Inspecione a causa

Use o **Analisador de Áudio** para comparar picos de formas de onda, espectro, altura e níveis. Um pico achatado pode indicar recorte. Uma banda espectral persistente durante o silêncio pode indicar zumbido. Compare possíveis problemas no original e na conversão antes de decidir qual estágio alterar.

Leia [Preparar um conjunto de dados de voz](../../model-training/dataset-preparation.md) para planos de gravação e avaliação.
