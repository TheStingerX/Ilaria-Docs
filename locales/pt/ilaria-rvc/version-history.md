# Histórico de versões e diferenças de lançamento

## Qual versão esta documentação descreve?

A fonte pública inspecionada para estas páginas se identifica como 2.1.2. Verifique sua versão instalada em **Outros → Atualizar Ilaria RVC**. Use **Todas as alterações até agora** para navegar pelas notas de lançamento por lançamento, mesmo off-line.

## Todos os lançamentos

 | Lançamento | Destaques |
| --- | --- |
| 2.1.2 | Os rótulos do cabeçalho foram uniformizados: **Ilaria’s Ko-Fi Shop**, **Ilaria’s RVC Website** e **Ilaria’s Docs**. |
| 2.1.1 | Foi adicionado um botão com coração para Ilaria Docs junto à ligação para o site. |
| 2.1.0 | Adicionado o botão do site, métricas de painel ao vivo para a execução ativa e melhor comportamento de inicialização e atualização no TensorBoard incorporado. |
 | 2.0.0 | Introduziu o painel de treinamento, TensorBoard integrado, relatórios de diagnóstico e visualizações de 12 segundos do Dataset Checker. Incorporadores opcionais tornaram-se downloads individuais. |
 | 1.9.3 | Introduziu processamento de áudio avançado, cinco formatos de exportação de inferência, incorporadores configuráveis ​​e instalação personalizada do HuBERT. |
 | 1.9.2 | Adicionados links públicos do Google Drive e MEGA ao downloader do modelo de voz. |
 | 1.9.1 | Adicionadas verificações de taxa de amostragem ao reutilizar o nome de um experimento, evitando uma falha de treinamento em configurações incompatíveis. |
 | 1.9.0 | Adicionado FCPE, importações de modelos transmitidos com cancelamento, uma guia Outros reorganizada e notas de versão off-line expansíveis. |
 | 1.8.1 | Sons de conclusão e teste atualizados, mantendo o som de erro do Windows. |
 | 1.8.0 | Introduziu o iniciador de console oculto, controle de reinicialização da interface do usuário, analisador de áudio e um layout de pasta compartilhada para modelos e seus índices. |
 | 1.7.2 | Conversão corrigida sem índice e arquivos de saída únicos e em lote nomeados após a voz selecionada. |
 | 1.7.1 | Suprimiu um rastreamento específico de fechamento de conexão do Windows, preservando outras mensagens de erro. |
 | 1.7.0 | Adicionado Edge e TTS offline do Windows, reprodutores de formas de onda e preparação de fundo para extração de pitch e modelos padrão suportados. |
 | 1.6.0 | Adicionada fila de treinamento persistente, metas de etapas exatas, opções RefineGAN e Spin-v2, downloads pré-treinados emparelhados, mais extratores de pitch e exportação ZIP. |
 | 1.5.2 | Diagnósticos aprimorados de lançamento duplicado e verificação da disponibilidade do conjunto de dados antes de cada estágio de treinamento. |
 | 1.5.1 | Pré-processamento bloqueado enquanto uma importação de conjunto de dados estava ativa ou o caminho do conjunto de dados estava inutilizável. Adicionado o painel do histórico de alterações offline. |
 | 1.5.0 | Introduziu importação e gerenciamento de conjuntos de dados com recurso de arrastar e soltar, o consultor de treinamento de PC e alertas opcionais de conclusão e erro. |
 | 1.4.0 | Adicionadas visualizações de treinamento, Parar e salvar recuperáveis ​​e o Verificador de conjunto de dados. |
 | 1.3.0 | Validei o caminho de atualização do 1.2, mostrei a versão instalada no console e preparei um pacote menor do Windows. |
 | 1.2.0 | Adicionado o atualizador integrado com verificação e recuperação, seleção de treinamento FP32/FP16 e informações do modelo. |
 | 1.1 Beta | Introduzida a interface temática, fluxo de trabalho de treinamento numerado, conversão de arrastar e soltar, correspondência automática de índices, importação e fusão de modelos e o glossário do aplicativo. |


Se um botão ou back-end for diferente em sua compilação, compare suas notas de versão antes de assumir uma falha na instalação.
