# NoRegretsRVC · Instalação

O NoRegretsRVC Beta 0.1.0 prepara fluxos Applio numa interface web e gera notebooks.

[GitHub](https://github.com/HunterThatsMe/NoRegretsRVC) · [Beta 0.1.0](https://github.com/HunterThatsMe/NoRegretsRVC/releases/tag/v0.1.0) · [Kaggle notebook](https://github.com/HunterThatsMe/NoRegretsRVC/blob/main/NoRegretsRVC_Kaggle.ipynb)

## Instalação

Instala Node.js 22 ou posterior com npm. Executa os comandos na pasta do projeto. Abre o endereço no terminal e mantém o processo ativo.

~~~bash
git clone https://github.com/HunterThatsMe/NoRegretsRVC.git
cd NoRegretsRVC
node --version
npm install
npm run dev
~~~

O repositório inclui um notebook Kaggle pronto a importar e um fluxo Streamlit.
