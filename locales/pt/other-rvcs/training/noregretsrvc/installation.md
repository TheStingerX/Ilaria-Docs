# NoRegretsRVC · Instalação

O NoRegretsRVC Beta 0.0 prepara fluxos Applio numa interface web e gera notebooks.

[GitHub](https://github.com/HunterThatsMe/NoRegretsRVC) · [Changelog](https://github.com/HunterThatsMe/NoRegretsRVC/blob/main/CHANGELOG.md)

## Instalação

Instala Node.js 22 ou posterior com npm. Executa os comandos na pasta do projeto. Abre o endereço no terminal e mantém o processo ativo.

~~~bash
git clone https://github.com/HunterThatsMe/NoRegretsRVC.git
cd NoRegretsRVC
node --version
npm install
npm run dev
~~~
