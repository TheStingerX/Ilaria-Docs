# Installazione e aggiornamenti

## Installa il pacchetto Windows

Scarica la build NVIDIA supportata da [Hugging Face](https://huggingface.co/TheStinger/Ilaria_RVC). Estrai l'intero archivio in una cartella locale scrivibile ed esegui `ILARIA_RVC.bat` lì. Il programma di avvio e il runtime in bundle devono rimanere insieme. Se non si apre alcuna scheda del browser, prova `http://127.0.0.1:6969` sullo stesso PC.

## Aggiorna un'installazione esistente

Apri **Altro → Aggiorna Ilaria RVC**. Controlla le note sulla versione, completa i lavori attivi ed esegui il backup di modelli, set di dati e stato dell'esperimento prima di scegliere **Scarica e riavvia**. Mantieni aperto il launcher durante l'aggiornamento. Se fallisce, annota il primo errore e inizia con `ILARIA_RVC_LOGS.bat` per una console diagnostica.
