# Controllo set di dati e analizzatore audio

[Scarica Ilaria RVC 2.4.0 per Windows (ZIP)](https://huggingface.co/TheStinger/Ilaria_RVC/resolve/main/releases/2.4.0/ILARIA_RVC-2.4.0.zip?download=true)

## Rivedi le registrazioni originali

Utilizza il **Controllo set di dati** per individuare possibili ritagli, lunghe pause, file illeggibili e livelli attivi incoerenti. Ascolta gli intervalli contrassegnati prima della modifica. Conserva le pause intenzionali e la pronuncia silenziosa quando appartengono alla voce prevista.

## Ispeziona la causa

Utilizza l'**Analizzatore audio** per confrontare i picchi, lo spettro, l'intonazione e i livelli della forma d'onda. Un picco appiattito può indicare un ritaglio. Una banda spettrale persistente durante il silenzio può indicare un ronzio. Confronta i problemi sospetti sull'originale e sulla conversione prima di decidere quale fase modificare.

Leggi [Preparare un set di dati vocali](../../model-training/dataset-preparation.md) per i piani di registrazione e valutazione.
