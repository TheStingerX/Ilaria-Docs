# Modelli e file RVC

Un modello RVC modifica il carattere vocale di una registrazione esistente. Inizia con una registrazione vocale isolata in modo che l'audio di sottofondo non interferisca con la conversione.

 | File | Scopo |
| --- | --- |
 | `.pth` | Checkpoint del modello utilizzato per convertire la voce. |
 | `.index` | Indice di recupero opzionale. Utilizzare l'indice corrispondente fornito con il modello. |

Se il risultato sembra innaturale, prova un input pulito e confronta con l'indice disabilitato. Regola gradualmente l'intonazione e riproduci lo stesso brano per ogni confronto.
