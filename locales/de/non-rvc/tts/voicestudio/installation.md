# VoiceStudio · Installation

[VoiceStudio v0.5.8](https://github.com/debpalash/VoiceStudio/releases/tag/v0.5.8) · [GitHub](https://github.com/debpalash/VoiceStudio)

## Vorbereitung

Wähle das Paket der Version 0.5.8 für dein System. Unter Windows x64 nutze die x64-EXE, auf Apple Silicon das arm64-DMG und auf Linux x64 DEB oder AppImage. Windows ARM kann das x64-Backend emulieren. Auf Intel-Macs prüfe die Option für ein entferntes Backend.

## Erster Test

Warte beim ersten Start auf das Backend. Lade im Modellmanager nur die benötigte Engine herunter und prüfe den Speicherplatz. Erzeuge danach einen kurzen Testsatz.
