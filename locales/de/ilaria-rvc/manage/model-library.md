# Modellbibliothek und Zusammenführung

[Ilaria RVC 2.4.0 für Windows herunterladen (ZIP)](https://huggingface.co/TheStinger/Ilaria_RVC/resolve/main/releases/2.4.0/ILARIA_RVC-2.4.0.zip?download=true)

[Bedienelemente in Other](other-buttons.md)

## Importieren und prüfen

Öffnen Sie **Andere** und importieren Sie ein unterstütztes lokales Modell oder verwenden Sie die Download-Steuerung. Halten Sie einen Prüfpunkt und seinen eigenen Index zusammen. Aktualisieren Sie die Rückschlussliste und bestätigen Sie die beabsichtigte Stimme vor dem Testen. Verwenden Sie **Modellinformationen**, um die in der Datei gespeicherte Abtastrate, Architektur und Präzision zu überprüfen.

## Kompatible Stimmen zusammenführen

Wählen Sie zwei Inferenzprüfpunkte und führen Sie zuerst die Kompatibilitätsprüfung durch. Verwenden Sie das Mischungsverhältnis, um festzulegen, wie viel Gewicht die einzelnen Zutaten beitragen. Speichern Sie unter einem neuen Namen und testen Sie das Ergebnis bei deaktiviertem Abruf. Ein vorhandener Index gehört zu dem Modell und den Funktionen, für die er erstellt wurde.
