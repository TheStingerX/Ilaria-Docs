# Installation und Updates

## Installieren Sie das Windows-Paket

Laden Sie den unterstützten NVIDIA-Build von [Hugging Face](https://huggingface.co/TheStinger/Ilaria_RVC)] herunter. Extrahieren Sie das gesamte Archiv in einen beschreibbaren lokalen Ordner und führen Sie dort `ILARIA_RVC.bat` aus. Der Launcher und die gebündelte Laufzeit müssen zusammen bleiben. Wenn sich kein Browser-Tab öffnet, versuchen Sie es mit `http://127.0.0.1:6969` auf demselben PC.

## Eine bestehende Installation aktualisieren

Öffnen Sie **Andere → Ilaria RVC aktualisieren**. Überprüfen Sie die Versionshinweise, beenden Sie aktive Jobs und sichern Sie Modelle, Datensätze und Experimentstatus, bevor Sie **Herunterladen und neu starten** wählen. Lassen Sie den Launcher während des Updates geöffnet. Wenn dies fehlschlägt, notieren Sie den ersten Fehler und beginnen Sie mit `ILARIA_RVC_LOGS.bat` für eine Diagnosekonsole.
