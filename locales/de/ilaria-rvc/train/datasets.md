# Datensatzprüfer und Audioanalysator

[Ilaria RVC 2.4.0 für Windows herunterladen (ZIP)](https://huggingface.co/TheStinger/Ilaria_RVC/resolve/main/releases/2.4.0/ILARIA_RVC-2.4.0.zip?download=true)

## Überprüfen Sie die Originalaufnahmen

Verwenden Sie den **Datensatzprüfer**, um mögliche Überschneidungen, lange Pausen, unlesbare Dateien und inkonsistente aktive Pegel zu finden. Hören Sie sich markierte Bereiche an, bevor Sie sie bearbeiten. Behalten Sie absichtliche Pausen und eine ruhige Übermittlung bei, wenn sie zur beabsichtigten Stimme gehören.

## Untersuchen Sie die Ursache.

Verwenden Sie den **Audioanalysator**, um Wellenformspitzen, Spektrum, Tonhöhe und Pegel zu vergleichen. Ein abgeflachter Peak kann auf Clipping hinweisen. Ein anhaltendes Spektralband während der Stille kann auf Brummen hinweisen. Vergleichen Sie vermutete Probleme beim Original und beim Umbau, bevor Sie entscheiden, welche Phase geändert werden soll.

Lesen Sie [Vorbereiten eines Sprachdatensatzes](../../model-training/dataset-preparation.md) für Aufzeichnungs- und Auswertungspläne.
