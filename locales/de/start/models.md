# RVC-Modelle und -Dateien

Ein RVC-Modell verändert den Stimmcharakter einer vorhandenen Aufnahme. Beginnen Sie mit einer isolierten Sprachaufnahme, damit Hintergrundgeräusche die Konvertierung nicht beeinträchtigen.

 | Datei | Zweck |
| --- | --- |
 | `.pth` | Modellprüfpunkt, der zur Konvertierung der Stimme verwendet wird. |
 | `.index` | Optionaler Abrufindex. Verwenden Sie den mit dem Modell gelieferten passenden Index. |

Wenn das Ergebnis unnatürlich klingt, versuchen Sie es mit einer sauberen Eingabe und vergleichen Sie es mit dem deaktivierten Index. Passen Sie die Tonhöhe schrittweise an und spielen Sie bei jedem Vergleich denselben Ausschnitt ab.
