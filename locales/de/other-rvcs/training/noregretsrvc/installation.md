# NoRegretsRVC · Installation

NoRegretsRVC Beta 0.0 bereitet Applio-Workflows in einer Weboberfläche vor und erzeugt Notebooks.

[GitHub](https://github.com/HunterThatsMe/NoRegretsRVC) · [Changelog](https://github.com/HunterThatsMe/NoRegretsRVC/blob/main/CHANGELOG.md)

## Installation

Installiere Node.js 22 oder neuer mit npm. Führe die Befehle im Projektordner aus. Öffne die URL aus dem Terminal und lasse den Prozess laufen.

~~~bash
git clone https://github.com/HunterThatsMe/NoRegretsRVC.git
cd NoRegretsRVC
node --version
npm install
npm run dev
~~~
