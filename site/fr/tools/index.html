Choisissez une application RVC

Comparez les applications compatibles pour la conversion vocale en direct, la conversion de fichiers et la formation.

Ilaria RVC 2.5.1 AMD Preview · AMD Preview est un paquet 2.5.1 distinct pour Radeon compatibles, sous Windows 11 via WSL2 ou Ubuntu 22.04 natif. Il utilise Python 3.10, PyTorch 2.6.0 et ROCm 6.4.2. Le paquet et le lanceur ont été vérifiés. L’entraînement, la reprise et la conversion complète sur Radeon restent à valider.

Télécharger Ilaria RVC 2.4.7 pour Windows (ZIP)

Vous pouvez aussi utiliser Ilaria RVC sur Kaggle avec son GPU distant, même si votre ordinateur n’a pas de GPU NVIDIA. Ilaria RVC on Kaggle

Pour installer, configurer ou dépanner une application, consultez les guides pas à pas par application.

Commencez par ce que vous voulez faire. Un changeur de voix en direct traite le flux du microphone pendant que vous parlez. Un convertisseur de fichiers traite un enregistrement et enregistre la sortie pour l'éditer ou l'exporter. Un entraîneur transforme un ensemble de données d'enregistrements d'un locuteur en modèle. Certaines applications proposent les trois flux de travail. La version que vous installez détermine le matériel graphique et les formats de modèle que vous pouvez utiliser.

Vonovox (recommandé pour une utilisation NVIDIA en direct)

Dernière version (bêta) · Vonovox 2.0.0 Beta 3 (ZIP)

Vonovox est un changeur de voix en temps réel Windows qui charge les modèles RVC v2 et utilise NVIDIA CUDA. Choisissez-le si votre objectif principal est la conversion du microphone et que vous disposez d'une carte NVIDIA prise en charge. La liste des packages comprend des versions et des correctifs pour des générations de GPU spécifiques, alors vérifiez les noms de fichiers et les instructions de publication avant de choisir une archive. Utilisez le référentiel Hugging Face de l'éditeur pour les téléchargements. Téléchargements officiels Vonovox · Matériel Vonovox et notes de configuration

Pour une première exécution, chargez votre voix RVC v2 et écoutez un court test de microphone avant d'acheminer l'audio vers une autre application. Réduisez ensuite progressivement la taille du bloc tout en parlant normalement. Restaurez le réglage précédent si vous entendez des coupures ou des syllabes hachées. Testez à nouveau avec le jeu ou l'application de streaming que vous prévoyez d'utiliser, car les deux partagent le même GPU. Configuration audio Vonovox

w-okada VCClient

VCClient gère la conversion vocale en direct avec un client et un serveur. Vous pouvez les exécuter ensemble sur une machine ou placer le serveur sur une deuxième machine pour éloigner la charge de travail de conversion de votre ordinateur principal. Sélectionnez une version prenant en charge le modèle RVC que vous souhaitez charger. Les téléchargements maintenus sont en direct sur Hugging Face, et le README en anglais du projet explique les options Windows standard, Windows CUDA, Apple Silicon et Linux. LISEZMOI anglais VCClient · Téléchargements officiels VCClient

Vérifiez le format du modèle ainsi que l'accélérateur. Par exemple, les anciennes instructions Windows v1 du projet limitent l'accélération GPU AMD et Intel aux modèles ONNX. Un fichier PyTorch .pth et un fichier .onnx exporté peuvent avoir des chemins matériels différents dans la même application. La norme Windows v2 documente les options DirectML et CPU. Notes sur la construction et le format du modèle de VCClient

Okada TG Developed Fork (TGR)

Le projet tg-develop/voice-changer est un fork communautaire dans la famille w-okada via le fork deiteris. Il se concentre sur RVC en direct et documente les versions Windows distinctes pour NVIDIA CUDA et DirectML sur du matériel AMD ou Intel compatible. Sa documentation couvre également l'utilisation du processeur, Linux et les versions expérimentales de macOS pour Apple Silicon et Intel. Configuration de TGR et configuration système requise · Version de TGR

Sous Windows, utilisez les instructions correspondant à la version que vous avez téléchargée. La version DirectML expose une liste différente d'extracteurs de pitch de la version NVIDIA, donc les préréglages de l'édition CUDA peuvent nécessiter un ajustement. Comparez la stabilité audio avec vos applications habituelles en cours d'exécution avant de vous fier à la configuration pour un enregistrement ou un streaming.

Ilaria RVC

Le package Windows actuel est NVIDIA uniquement. Utilisez-le lorsque vous souhaitez basculer entre la conversion d'enregistrements, la génération de paroles, la formation, la vérification des métadonnées d'un modèle et l'inspection des formes d'onde ou des spectrogrammes dans l'analyseur audio. Les installations existantes peuvent rechercher des mises à jour sous Autre → Mettre à jour Ilaria RVC. Téléchargements d'Ilaria RVC · Projet README et notes de version

RVC GUI

L'interface graphique RVC de Tiger14n est une interface de bureau autonome pour convertir des fichiers audio. Il peut importer un ZIP contenant l'inférence .pth et sa correspondance .index lorsqu'elle est disponible. Son référentiel est archivé, utilisez donc ses instructions pour un flux de travail qui nécessite spécifiquement cette application. L'interface graphique en temps réel du projet RVC en amont, également nommé, est un lanceur distinct. Dépôt et configuration de l'interface graphique RVC

Applio

Applio prend en charge la gestion des modèles vocaux RVC, la conversion de fichiers, la formation et le temps réel. Ses éditions Desktop et Python/Gradio ont des flux de configuration différents. La documentation du bureau identifie NVIDIA CUDA, les configurations AMD prises en charge et Apple MPS et explique comment vérifier l'état du moteur après l'installation. Utilisez les Étapes de conversion Applio pour votre édition.

Interface utilisateur Web RVC

Retrieval-based-Voice-Conversion-WebUI est le projet RVC en amont. Son WebUI gère la formation et l'inférence de fichiers. L'interface graphique en temps réel du projet possède son propre lanceur. La branche principale documente les dépendances CUDA distinctes pour les cartes NVIDIA plus récentes et plus anciennes, ainsi qu'un ensemble de dépendances CPU pour les systèmes AMD et Intel. Sous Windows, DirectML peut être disponible pour les opérations prises en charge. Suivez les Étapes de conversion principales pour le package Windows.

Redpanda-vc

Redpanda VC propose entraînement, inférence sur fichier et conversion en temps réel pour RVC et Causal Voice Changer, sur le bureau et dans la WebUI. Utilisez .pth avec RVC et .cvc avec CVC. Version précompilée pour Windows x64

Comparez les applications avec la même voix

  1. Choisissez le package adapté à votre système d'exploitation, GPU et format de modèle. Vérifiez si l'application prend en charge la génération RVC et l'encodeur de fonctionnalités de votre modèle.
  2. Commencez par le même court enregistrement ou répétez les mêmes quelques phrases dans votre microphone. Chargez le même modèle d'inférence et son index correspondant dans les deux applications si pris en charge.
  3. Utilisez le même pitch shift et désactivez les effets vocaux optionnels pour la première comparaison. Jugez des mots clairs, une hauteur stable et des pauses naturelles avant d'ajuster le son.
  4. Pour une utilisation en direct, exécutez l'application de jeu, d'appel ou de streaming que vous utilisez normalement et enregistrez la sortie acheminée pendant au moins une minute. Écoutez les interruptions, les coupures brutales et les retards audio avant de réduire la mémoire tampon.
