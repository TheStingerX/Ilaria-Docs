# VoiceStudio · Instalação

[VoiceStudio v0.5.8](https://github.com/debpalash/VoiceStudio/releases/tag/v0.5.8) · [GitHub](https://github.com/debpalash/VoiceStudio)

## Preparação

Escolhe o pacote 0.5.8 para o teu sistema. No Windows x64 usa o EXE x64, no Apple Silicon o DMG arm64 e no Linux x64 DEB ou AppImage. No Windows ARM, o backend x64 pode correr por emulação. Num Mac Intel, verifica o backend remoto.

## Primeiro teste

Aguarda pela preparação do backend. No gestor de modelos, descarrega o motor necessário e verifica o espaço livre. Gera primeiro uma frase curta.
