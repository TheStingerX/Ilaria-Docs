Para ver los pasos de instalación, configuración y solución de problemas, consulta las guías de cada aplicación.

Comienza con lo que quieres hacer. Un cambiador de voz en vivo procesa la transmisión del micrófono mientras hablas. Un convertidor de archivos procesa una grabación y guarda el resultado para editarlo o exportarlo. Un entrenador convierte un conjunto de datos de las grabaciones de un orador en un modelo. Algunas aplicaciones ofrecen los tres flujos de trabajo. La compilación que instale determina qué hardware de gráficos y formatos de modelo puede utilizar.

Vonovox (recomendado para uso en vivo de NVIDIA)

Versión más reciente (beta) · Vonovox 2.0.0 Beta 3 (ZIP)

Vonovox es un cambiador de voz en tiempo real de Windows que carga modelos RVC v2 y utiliza NVIDIA CUDA. Elígelo si tu objetivo principal es la conversión de micrófono y tienes una tarjeta NVIDIA compatible. La lista de paquetes incluye compilaciones y parches para generaciones específicas de GPU, así que verifique los nombres de archivos y las instrucciones de lanzamiento antes de elegir un archivo. Utilice el repositorio Hugging Face del editor para realizar descargas. Descargas oficiales de Vonovox · Notas de configuración y hardware de Vonovox

Para una primera ejecución, cargue su voz RVC v2 y escuche una breve prueba de micrófono antes de enrutar el audio a otra aplicación. Luego reduzca el tamaño del bloque gradualmente mientras habla normalmente. Restaure la configuración anterior si escucha omisiones o sílabas cortadas. Pruebe nuevamente junto con el juego o la aplicación de transmisión que planea usar, porque ambos comparten la misma GPU. Configuración de audio Vonovox

w-okada VCClient

VCClient maneja la conversión de voz en vivo con un cliente y un servidor. Puede ejecutarlos juntos en una máquina o colocar el servidor en una segunda máquina para alejar la carga de trabajo de conversión de su computadora principal. Seleccione una versión que admita el modelo RVC que desea cargar. Las descargas mantenidas se encuentran en Hugging Face y el archivo README en inglés del proyecto explica las opciones del estándar de Windows, Windows CUDA, Apple Silicon y Linux. VCClient English README · Descargas oficiales de VCClient

Consulta el formato del modelo así como el acelerador. Por ejemplo, las instrucciones anteriores de Windows v1 del proyecto limitan la aceleración de GPU AMD e Intel a los modelos ONNX. Un archivo PyTorch .pth y un archivo .onnx exportado pueden tener diferentes rutas de hardware en la misma aplicación. El estándar de Windows v2 documenta las opciones de DirectML y CPU. Notas sobre formato de modelo y compilación de VCCClient

Okada TG Developed Fork (TGR)

El proyecto tg-develop/voice-changer es un fork comunitaria de la familia w-okada a través de el fork deiteris. Se centra en RVC en vivo y documenta compilaciones separadas de Windows para NVIDIA CUDA y DirectML en hardware AMD o Intel compatible. Su documentación también cubre el uso de CPU, Linux y versiones experimentales de macOS para Apple Silicon e Intel. Configuración de TGR y requisitos del sistema · Versiones de TGR

En Windows, utilice las instrucciones de la compilación que descargó. La compilación DirectML expone una lista diferente de extractores de tono de la compilación NVIDIA, por lo que es posible que sea necesario ajustar los ajustes preestablecidos de la edición CUDA. Compare la estabilidad del audio con sus aplicaciones habituales antes de confiar en la configuración para una grabación o transmisión.

Ilaria RVC

El paquete actual de Windows es solo NVIDIA. Úselo cuando desee alternar entre convertir grabaciones, generar voz, entrenar, verificar los metadatos de un modelo e inspeccionar formas de onda o espectrogramas en el Analizador de audio. Las instalaciones existentes pueden buscar actualizaciones en Otro → Actualizar Ilaria RVC. Descargas de Ilaria RVC · LÉAME del proyecto y notas de la versión

RVC GUI

La RVC GUI de Tiger14n es una interfaz de escritorio independiente para convertir archivos de audio. Puede importar un ZIP que contenga la inferencia .pth y su coincidencia .index cuando esté disponible. Su repositorio está archivado, así que utilice sus instrucciones para un flujo de trabajo que requiera específicamente esta aplicación. La GUI en tiempo real del proyecto RVC anterior, con un nombre similar, es un iniciador independiente. Repositorio y configuración de RVC GUI

Applio

Applio admite la gestión de modelos de voz RVC, la conversión de archivos, la capacitación y el tiempo real. Sus ediciones Desktop y Python/Gradio tienen diferentes flujos de configuración. Los documentos de escritorio identifican NVIDIA CUDA, las configuraciones AMD compatibles y Apple MPS y explican cómo verificar el estado del motor después de la instalación. Utilice los pasos de conversión de Applio para su edición.

Interfaz de usuario web RVC

WebUI de conversión de voz basada en recuperación es el proyecto RVC ascendente. Su WebUI maneja el entrenamiento y la inferencia de archivos. La GUI en tiempo real del proyecto tiene su propio lanzador. La rama principal documenta dependencias CUDA separadas para tarjetas NVIDIA más nuevas y antiguas, además de un conjunto de dependencias de CPU para sistemas AMD e Intel. En Windows, DirectML puede estar disponible para operaciones compatibles. Siga los Pasos de conversión principales para el paquete de Windows.

Redpanda-vc

Redpanda-vc es un fork de Applio cuya interfaz en tiempo real admite RVC, Beatrice y Rectified Flow. Ofrece múltiples familias de modelos, así que seleccione el flujo de trabajo RVC para una voz RVC. En su modo de navegador en tiempo real, el proyecto documenta la asignación de transmisiones a GPU particulares y señala que Beatrice se ejecuta en la CPU. Esas opciones de recursos se aplican a Redpanda-vc y su motor seleccionado. Repositorio Redpanda-vc y motores compatibles

Compara aplicaciones con la misma voz

  1. Elige el paquete para tu sistema operativo, GPU y formato de modelo. Compruebe si la aplicación es compatible con la generación RVC y el codificador de funciones de su modelo.
  2. Comience con la misma grabación breve o repita las mismas frases en su micrófono. Cargue el mismo modelo de inferencia y su índice coincidente en ambas aplicaciones, si es compatible.
  3. Utilice el mismo cambio de tono y desactive los efectos de voz opcionales para la primera comparación. Juzgue palabras claras, tono estable y pausas naturales antes de ajustar el sonido.
  4. Para uso en vivo, ejecute la aplicación de juegos, llamadas o transmisión que usa normalmente y grabe la salida enrutada durante al menos un minuto. Escuche espacios, cortes bruscos y audio retrasado antes de reducir el búfer.
