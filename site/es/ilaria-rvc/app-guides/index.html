Elige según la tarea y la GPU

Usa Ilaria RVC para entrenar modelos y convertir grabaciones. Para el micrófono en directo en Windows, elige Vonovox con NVIDIA u Okada TG Developed Fork con AMD o Intel compatible. Para otras tareas, empieza por Applio o Redpanda-vc.

Entrena un modelo con Ilaria RVC

Prepara grabaciones limpias de una sola persona. Preprocesa los archivos, extrae características e inicia el entrenamiento. Compara varios checkpoints con audios reservados para las pruebas. Si generas un índice, guárdalo con su modelo.

Prepara el conjunto de datos · Proceso de entrenamiento · Controles de entrenamiento

Convierte archivos con Ilaria RVC

Importa un .pth de inferencia y añade su .index si lo tienes. Convierte un WAV corto sin efectos. Guarda el resultado de referencia, cambia un ajuste cada vez y prueba varios clips antes de convertir por lotes. Usa Kaggle para entrenar o convertir si no tienes una GPU local adecuada.

Inferencia individual y por lotes · Controles de inferencia

Convierte el micrófono en directo

Con NVIDIA, elige el paquete de Vonovox para tu GPU. Con AMD o Intel, prueba la versión DirectML de TGR si tu tarjeta es compatible. Escucha el resultado con auriculares antes de enviarlo a un cable virtual. Selecciona el extremo de grabación de ese cable como micrófono en Discord, OBS o tu juego. Si hay cortes, aumenta el búfer.

Otras tareas con Applio o Redpanda-vc

Applio reúne la síntesis de voz y la gestión de modelos. Redpanda-vc permite comparar RVC, Beatrice y Rectified Flow y probar el directo en el navegador o en el escritorio. Elige el motor RVC para un modelo RVC.

Guarda una prueba de referencia

Compara archivos con la misma fuente y el mismo volumen. Para el directo, graba una prueba en la aplicación de destino. Si el problema solo aparece allí, revisa el cable virtual, el micrófono seleccionado y la monitorización.

Aplicación Cuándo usarla Hardware y notas de compilación
Ilaria RVC Conversión de archivos, TTS, entrenamiento y análisis de audio La distribución actual de Windows es solo NVIDIA.
RVC WebUI (Mainline - Original RVC) Entrenamiento e inferencia ascendentes, con un iniciador en tiempo real independiente NVIDIA CUDA en Windows y Ubuntu. La configuración de CPU ascendente cubre sistemas AMD e Intel, con posible uso de DirectML en Windows.
Applio Conversión de archivos, capacitación y tiempo real en una sola aplicación La documentación de escritorio enumera NVIDIA CUDA, configuraciones AMD compatibles y Apple MPS. La disponibilidad depende de la edición y el motor.
Redpanda-vc Una fork de Applio para experimentar con múltiples motores de conversión de voz El repositorio incluye un contenedor CUDA y documenta la selección de GPU para transmisiones WebUI. Verifique el motor seleccionado y constrúyalo para otros backends.
RVC GUI Conversión simple de archivos locales en la interfaz de escritorio heredada Archivado. El proyecto documenta Windows NVIDIA CUDA y una solución histórica de Apple Silicon.
Vonovox Recomendado para RVC v2 en vivo en Windows con NVIDIA Solo NVIDIA CUDA. Haga coincidir el paquete Hugging Face con su generación de GPU.
w-okada VCClient Conversión en vivo en varios sistemas operativos Windows CUDA y paquetes estándar, incluidos DirectML o CPU, cuando sean compatibles. Separe las rutas de configuración de Apple Silicon y Linux.
Okada TG Developed Fork Live RVC con opciones documentadas para usuarios de AMD, Intel y CPU Windows CUDA o DirectML. Las compilaciones de Linux y macOS experimentales tienen instrucciones separadas.
RVC Blue Conversión de voz en tiempo real en Windows NVIDIA CUDA 12.8 / 11.8 (Windows)
