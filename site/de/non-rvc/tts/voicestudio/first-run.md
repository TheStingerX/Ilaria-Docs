# VoiceStudio · Erste Synthese

[VoiceStudio v0.5.8 · Erste Synthese](https://github.com/debpalash/VoiceStudio/blob/v0.5.8/README.md)

## Vorbereitung

Wähle eine installierte Engine, eine Stimme und eine unterstützte Sprache. Schreibe einen kurzen Satz, erzeuge Audio und höre ihn vollständig an. Speichere das Ergebnis.

## Erster Test

Halte Text und Stimme beim Einstellungsvergleich konstant. Schreibe Zahlen und Abkürzungen bei falscher Aussprache aus.
