Vonovox (empfohlen für den Live-NVIDIA-Einsatz)

Neueste Version (Beta) · Vonovox 2.0.0 Beta 3 (ZIP)

Vonovox ist ein Echtzeit-Sprachwechsler für Windows, der RVC v2-Modelle lädt und NVIDIA CUDA verwendet. Wählen Sie diese Option, wenn Ihr Hauptziel die Mikrofonkonvertierung ist und Sie über eine unterstützte NVIDIA-Karte verfügen. Die Paketliste enthält Builds und Patches für bestimmte GPU-Generationen. Überprüfen Sie daher die Dateinamen und Versionsanweisungen, bevor Sie ein Archiv auswählen. Nutzen Sie für Downloads das Hugging Face-Repository des Herausgebers. Offizielle Vonovox-Downloads · Vonovox-Hardware- und Setup-Hinweise

Laden Sie zum ersten Mal Ihre RVC v2-Stimme und hören Sie sich einen kurzen Mikrofontest an, bevor Sie Audio an eine andere App weiterleiten. Verringern Sie dann die Blockgröße schrittweise, während Sie normal sprechen. Stellen Sie die vorherige Einstellung wieder her, wenn Sie Aussetzer oder abgehackte Silben hören. Testen Sie es noch einmal zusammen mit dem Spiel oder der Streaming-App, die Sie verwenden möchten, da beide die gleiche GPU verwenden. Vonovox Audiokonfiguration

w-okada VCClient

VCClient übernimmt die Live-Sprachkonvertierung mit einem Client und einem Server. Sie können sie zusammen auf einem Computer ausführen oder den Server auf einem zweiten Computer platzieren, um die Konvertierungsarbeitslast von Ihrem Hauptcomputer zu verlagern. Wählen Sie eine Version aus, die das RVC-Modell unterstützt, das Sie laden möchten. Die gepflegten Downloads sind live auf Hugging Face verfügbar, und in der englischen README-Datei des Projekts werden die Windows-Standard-, Windows CUDA-, Apple Silicon- und Linux-Optionen erläutert. VCClient English README · Offizielle VCClient-Downloads

Überprüfen Sie das Modellformat sowie den Beschleuniger. Beispielsweise beschränken die älteren Windows v1-Anweisungen des Projekts die AMD- und Intel-GPU-Beschleunigung auf ONNX-Modelle. Eine PyTorch-Datei .pth und eine exportierte Datei .onnx können in derselben App unterschiedliche Hardwarepfade haben. Windows Standard v2 dokumentiert DirectML- und CPU-Optionen. VCClient-Build- und Modellformat-Hinweise

Okada TG Developed Fork (TGR)

Das tg-develop/voice-changer-Projekt ist über den Deiteris-Fork ein Community-Fork in der W-Okada-Familie. Es konzentriert sich auf Live-RVC und dokumentiert separate Windows-Builds für NVIDIA CUDA und für DirectML auf kompatibler AMD- oder Intel-Hardware. Die Dokumentation deckt auch die CPU-Nutzung, Linux und experimentelle macOS-Builds für Apple Silicon und Intel ab. TGR-Setup und Systemanforderungen · TGR-Versionen

Befolgen Sie unter Windows die Anweisungen für den heruntergeladenen Build. Der DirectML-Build stellt eine andere Liste von Pitch-Extraktoren als der NVIDIA-Build bereit, sodass Voreinstellungen aus der CUDA-Edition möglicherweise angepasst werden müssen. Vergleichen Sie die Audiostabilität mit der Ihrer üblichen Apps, bevor Sie sich für eine Aufnahme oder einen Stream auf das Setup verlassen.

Ilaria RVC

Das aktuelle Windows-Paket ist nur NVIDIA. Verwenden Sie es, wenn Sie zwischen der Konvertierung von Aufzeichnungen, der Sprachgenerierung, dem Training, der Überprüfung der Metadaten eines Modells und der Prüfung von Wellenformen oder Spektrogrammen im Audioanalysator wechseln möchten. Bestehende Installationen können unter Andere → Ilaria RVC aktualisieren nach Updates suchen. Ilaria RVC-Downloads · Projekt-README und Versionshinweise

RVC-GUI

Die RVC-GUI von Tiger14n ist eine eigenständige Desktop-Oberfläche zum Konvertieren von Audiodateien. Es kann eine ZIP-Datei importieren, die die Inferenz .pth und die entsprechende .index enthält, sofern verfügbar. Das Repository ist archiviert. Verwenden Sie daher die Anweisungen für einen Workflow, der diese App speziell erfordert. Die gleichnamige Echtzeit-GUI des Upstream-RVC-Projekts ist ein separater Launcher. RVC GUI-Repository und Setup

Applio

Applio unterstützt RVC-Sprachmodellverwaltung, Dateikonvertierung, Schulung und Echtzeit. Die Desktop- und Python/Gradio-Editionen verfügen über unterschiedliche Einrichtungsabläufe. In den Desktop-Dokumenten werden NVIDIA CUDA, unterstützte AMD-Konfigurationen und Apple MPS identifiziert und erläutert, wie der Engine-Status nach der Installation überprüft wird. Verwenden Sie die Applio-Konvertierungsschritte für Ihre Edition.

RVC-WebUI

Retrieval-based-Voice-Conversion-WebUI ist das Upstream-RVC-Projekt. Seine WebUI übernimmt das Training und die Dateiinferenz. Die Echtzeit-GUI des Projekts verfügt über einen eigenen Launcher. Der Hauptzweig dokumentiert separate CUDA-Abhängigkeiten für neuere und ältere NVIDIA-Karten sowie einen CPU-Abhängigkeitssatz für AMD- und Intel-Systeme. Unter Windows ist DirectML möglicherweise für unterstützte Vorgänge verfügbar. Befolgen Sie die Hauptkonvertierungsschritte für das Windows-Paket.

Redpanda-vc

Redpanda VC unterstützt Training, Datei-Inferenz und Echtzeit für RVC und Causal Voice Changer in der Desktop-App und WebUI. Verwende .pth für RVC und .cvc für CVC. Vorkompilierte Version für Windows x64

Apps mit derselben Stimme vergleichen

  1. Wählen Sie das Paket für Ihr Betriebssystem, Ihre GPU und Ihr Modellformat. Prüfen Sie, ob die App die RVC-Generierung und den Feature-Encoder Ihres Modells unterstützt.
  2. Beginnen Sie mit derselben kurzen Aufnahme oder wiederholen Sie dieselben paar Sätze in Ihr Mikrofon. Laden Sie dasselbe Inferenzmodell und seinen passenden Index in beide Apps, sofern dies unterstützt wird.
  3. Verwenden Sie für den ersten Vergleich die gleiche Tonhöhenverschiebung und deaktivieren Sie optionale Spracheffekte. Beurteilen Sie klare Worte, eine stabile Tonhöhe und natürliche Pausen, bevor Sie den Klang anpassen.
  4. Für den Live-Einsatz führen Sie die Spiel-, Anruf- oder Streaming-App aus, die Sie normalerweise verwenden, und zeichnen Sie die geroutete Ausgabe mindestens eine Minute lang auf. Achten Sie auf Lücken, harte Schnitte und verzögertes Audio, bevor Sie den Puffer reduzieren.

Replay

Replay · Installation und Verfügbarkeit

Offizielle Website · Internet Archive

Seit der Schließung von Weights.gg erhält Replay keinen Support und keine Updates mehr. Die offizielle Replay-Seite könnte jederzeit abgeschaltet werden. Das Internet Archive enthält die Installationsdateien von Replay 8.7.0. Für neue Installationen wird Replay nicht empfohlen. Seit der Schließung von Weights kann das archivierte Installationsprogramm die benötigten Dateien wahrscheinlich nicht mehr herunterladen, sodass die Installation möglicherweise fehlschlägt.
