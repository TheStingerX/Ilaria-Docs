# Ultimate Vocal Remover 6 (UVR6): Preparatory Guide

> **Pre-release status:** As of **November 21, 2026**, **UVR6 has not been released yet**. Developer **Anjok07** officially announced **Windows release on December 11, 2026**, with **macOS** and **Linux** versions following shortly after. Until UVR6 is published, continue using [UVR5](overview.md) or [MVSep](../mvsep/overview.md) for dataset and cover separation.

## What is officially announced for UVR6

Based on the official UVR announcement:

- **Redesigned interface:** Rebuilt from the ground up to be cleaner and faster, with native accessibility options and built-in **Dark**, **Light**, and custom color themes.
- **New Download Center:** Consolidates official and community separation models into a single searchable, sortable table explaining what each model does.
- **New architectures & Ensemble mode:** Supports newer community separation architectures alongside an **Ensemble** mode to blend outputs from multiple models for cleaner stems.
- **Built-in Audio Tools:** Adds tools for track alignment, matching, key changes, and tempo adjustments.
- **New Command-Line Interface (CLI):** Allows batch processing and scripted separations from a terminal using the same models and settings as the GUI.

## What is NOT confirmed yet

Do not assume exact VRAM requirements, installer size, or step-by-step UI migration paths until the December 11, 2026 release is published and tested. This page will be updated with verified installation and migration instructions after launch.
