# VoiceStudio · Reference voices and Voice Design

[VoiceStudio v0.5.8 · Reference voices and Voice Design](https://github.com/debpalash/VoiceStudio/blob/v0.5.8/docs/electron-voice-design.md)

## Use a reference recording

Choose clean single-speaker audio and obtain permission to use the voice. Import it in the cloning workspace and review the transcript if required. Avoid music, other speakers and clipping. Generate a new sentence and compare pronunciation and timbre with the reference.

## Describe a voice

In Voice Design, start with specific pacing, register and delivery, such as a calm reading with clear pauses. Compare descriptions using the same text. Save the voice or output as supported by the engine. Audition the result before applying it to a long project.

## Prepare two reference clips

1. Choose two permitted clips of the same speaker, one neutral and one with the desired delivery.
2. Listen with headphones. Reject music, overlapping speakers, strong reverb or distortion.
3. Import the neutral clip and enter the transcript if the engine requests it. Correct it before generating.
4. Test with a sentence different from the reference. Repeat with the second clip while keeping the engine and text fixed.

## Audition before saving a voice

Compare similarity, intelligibility and natural pauses. For long projects, also test a question, a number and a proper name. In Voice Design change one aspect at a time, such as pacing. If pronunciation worsens, verify language and text clarity first.
