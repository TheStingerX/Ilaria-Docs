Scegli un'app RVC

Confronta app compatibili per la conversione vocale dal vivo, la conversione di file e la formazione.

Scarica Ilaria RVC 2.4.7 per Windows (ZIP)

Puoi usare Ilaria RVC anche su Kaggle con la GPU remota, anche se il tuo computer ha una GPU AMD, Intel, integrata o poco potente. Ilaria RVC on Kaggle

Per le procedure complete di installazione, configurazione e risoluzione dei problemi, consulta le guide passo passo per app.

Inizia con quello che vuoi fare. Un cambia voce dal vivo elabora un flusso del microfono mentre parli. Un convertitore di file elabora una registrazione e salva l'output per la modifica o l'esportazione. Un formatore trasforma un set di dati delle registrazioni di un relatore in un modello. Alcune app offrono tutti e tre i flussi di lavoro. La build installata determina quale hardware grafico e formati di modello è possibile utilizzare.

Vonovox (consigliato per l'uso live con NVIDIA)

Ultima versione (beta) · Vonovox 2.0.0 Beta 3 (ZIP)

Vonovox è un cambia voce in tempo reale di Windows che carica i modelli RVC v2 e utilizza NVIDIA CUDA. Sceglilo se il tuo obiettivo principale è la conversione del microfono e hai una scheda NVIDIA supportata. L'elenco dei pacchetti include build e patch per generazioni di GPU specifiche, quindi controlla i nomi dei file e le istruzioni di rilascio prima di scegliere un archivio. Utilizza il repository Hugging Face dell'editore per i download. Download ufficiali di Vonovox · Note sull'hardware e sulla configurazione di Vonovox

Per una prima esecuzione, carica la tua voce RVC v2 e ascolta un breve test del microfono prima di indirizzare l'audio a un'altra app. Quindi ridurre gradualmente la dimensione del blocco mentre si parla normalmente. Ripristina l'impostazione precedente se senti interruzioni o sillabe spezzate. Esegui nuovamente il test insieme al gioco o all'app di streaming che prevedi di utilizzare, perché entrambi condividono la stessa GPU. Configurazione audio Vonovox

w-okada VCClient

VCClient gestisce la conversione vocale dal vivo con un client e un server. Puoi eseguirli insieme su un computer o posizionare il server su un secondo computer per spostare il carico di lavoro di conversione lontano dal computer principale. Seleziona una versione che supporti il ​​modello RVC che desideri caricare. I download gestiti si trovano su Hugging Face e il README inglese del progetto spiega le opzioni standard di Windows, Windows CUDA, Apple Silicon e Linux. LEGGIMI inglese di VCClient · Download ufficiali di VCClient

Controlla il formato del modello e l'acceleratore. Ad esempio, le vecchie istruzioni Windows v1 del progetto limitano l'accelerazione GPU AMD e Intel ai modelli ONNX. Un file PyTorch .pth e un file esportato .onnx possono avere percorsi hardware diversi nella stessa app. Lo standard di Windows v2 documenta le opzioni DirectML e CPU. Note sulla build di VCClient e sul formato del modello

Okada TG Developed Fork (TGR)

Il progetto tg-develop/voice-changer è un fork della comunità nella famiglia w-okada tramite il fork deiteris. Si concentra su RVC live e documenta build Windows separate per NVIDIA CUDA e DirectML su hardware AMD o Intel compatibile. La sua documentazione copre anche l'uso della CPU, Linux e le build sperimentali di macOS per Apple Silicon e Intel. Configurazione TGR e requisiti di sistema · Versioni TGR

Su Windows, utilizza le istruzioni per la build scaricata. La build DirectML espone un elenco diverso di estrattori di tonalità rispetto alla build NVIDIA, quindi le preimpostazioni dell'edizione CUDA potrebbero richiedere modifiche. Confronta la stabilità audio con le tue solite app in esecuzione prima di affidarti alla configurazione per una registrazione o uno streaming.

Ilaria RVC

Il pacchetto Windows attuale è solo NVIDIA. Usalo quando desideri passare dalla conversione delle registrazioni, alla generazione del parlato, all'addestramento, al controllo dei metadati di un modello e all'ispezione di forme d'onda o spettrogrammi nell'Analizzatore audio. Le installazioni esistenti possono verificare la presenza di aggiornamenti in Altro → Aggiorna Ilaria RVC. Download di Ilaria RVC · README del progetto e note di rilascio

GUI RVC

La GUI RVC di Tiger14n è un'interfaccia desktop autonoma per la conversione di file audio. Può importare un ZIP contenente l'inferenza .pth e la sua corrispondenza .index quando disponibile. Il suo repository è archiviato, quindi utilizza le sue istruzioni per un flusso di lavoro che richiede specificamente questa app. La Real-time GUI del progetto RVC upstream dal nome simile è un launcher separato. Repository e configurazione della GUI RVC

Applio

Applio supporta la gestione del modello vocale RVC, la conversione dei file, la formazione e il tempo reale. Le sue edizioni Desktop e Python/Gradio hanno flussi di configurazione diversi. La documentazione desktop identifica NVIDIA CUDA, le configurazioni AMD supportate e Apple MPS e spiega come controllare lo stato del motore dopo l'installazione. Utilizza i passaggi di conversione di Applio per la tua edizione.

RVC WebUI (Mainline - Original RVC)

WebUI basato sul recupero della conversione vocale è il progetto RVC upstream. La sua WebUI gestisce l'addestramento e l'inferenza dei file. La GUI in tempo reale del progetto ha il proprio launcher. Il ramo principale documenta le dipendenze CUDA separate per le schede NVIDIA più recenti e quelle meno recenti, oltre a un set di dipendenze CPU per i sistemi AMD e Intel. Su Windows, DirectML potrebbe essere disponibile per le operazioni supportate. Seguire i Passaggi di conversione della linea principale per il pacchetto Windows.

Redpanda-vc

Redpanda VC offre training, inferenza da file e conversione in tempo reale per RVC e Causal Voice Changer, nell’app desktop e nella WebUI. Usa .pth con RVC e .cvc con CVC. Release precompilata per Windows x64

Confronta le app con la stessa voce

  1. Scegli il pacchetto per il tuo sistema operativo, GPU e formato del modello. Controlla se l'app supporta la generazione RVC e il codificatore di funzionalità del tuo modello.
  2. Inizia con la stessa breve registrazione o ripeti le stesse poche frasi nel microfono. Carica lo stesso modello di inferenza e il relativo indice corrispondente in entrambe le app, se supportato.
  3. Usa lo stesso pitch shift e disattiva gli effetti vocali opzionali per il primo confronto. Giudica le parole chiare, l'intonazione stabile e le pause naturali prima di regolare il suono.
  4. Per l'utilizzo dal vivo, esegui il gioco, la chiamata o l'app di streaming che usi normalmente e registra l'output instradato per almeno un minuto. Ascolta eventuali lacune, tagli netti e audio ritardato prima di ridurre il buffer.
