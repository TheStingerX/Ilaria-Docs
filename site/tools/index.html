Choose an RVC app

Compare compatible apps for live voice conversion, file conversion, and training.

You can also run Ilaria RVC on Kaggle using its remote GPU. This option works even if your computer has no NVIDIA GPU. Ilaria RVC on Kaggle

For complete installation, configuration, and troubleshooting procedures, see the step-by-step app guides.

Start with what you want to do. A live voice changer processes a microphone stream while you talk. A file converter processes a recording and saves the output for editing or export. A trainer turns a dataset of a speaker's recordings into a model. Some apps offer all three workflows. The build you install determines which graphics hardware and model formats you can use.

Vonovox (recommended for live NVIDIA use)

Latest release (beta) · Vonovox 2.0.0 Beta 3 (ZIP)

Vonovox is a Windows realtime voice changer that loads RVC v2 models and uses NVIDIA CUDA. Choose it if your main goal is microphone conversion and you have a supported NVIDIA card. The package list includes builds and patches for specific GPU generations, so check the filenames and release instructions before choosing an archive. Use the publisher's Hugging Face repository for downloads. Official Vonovox downloads · Vonovox hardware and setup notes

For a first run, load your RVC v2 voice and listen to a short microphone test before routing audio into another app. Then lower the block size gradually while speaking normally. Restore the previous setting if you hear dropouts or chopped syllables. Test again alongside the game or streaming app you plan to use, because both share the same GPU. Vonovox audio configuration

w-okada VCClient

VCClient handles live voice conversion with a client and server. You can run them together on one machine or put the server on a second machine to move the conversion workload away from your main computer. Select a release that supports the RVC model you want to load. The maintained downloads live on Hugging Face, and the project's English README explains Windows standard, Windows CUDA, Apple Silicon, and Linux options. VCClient English README · Official VCClient downloads

Check the model format as well as the accelerator. For example, the project's older Windows v1 instructions limit AMD and Intel GPU acceleration to ONNX models. A PyTorch .pth file and an exported .onnx file can have different hardware paths in the same app. Windows standard v2 documents DirectML and CPU options. VCClient build and model-format notes

Okada TG Developed Fork (TGR)

The tg-develop/voice-changer project is a community fork in the w-okada family via the deiteris fork. It focuses on live RVC and documents separate Windows builds for NVIDIA CUDA and for DirectML on compatible AMD or Intel hardware. Its documentation also covers CPU use, Linux, and experimental macOS builds for Apple Silicon and Intel. TGR setup and system requirements · TGR releases

On Windows, use the instructions for the build you downloaded. The DirectML build exposes a different list of pitch extractors from the NVIDIA build, so presets from the CUDA edition may need adjustment. Compare audio stability with your usual apps running before relying on the setup for a recording or stream.

Ilaria RVC

The current Windows package is NVIDIA only. Use it when you want to switch between converting recordings, generating speech, training, checking a model's metadata, and inspecting waveforms or spectrograms in the Audio Analyzer. Existing installations can check for updates under Other → Update Ilaria RVC. Ilaria RVC downloads · Project README and release notes

RVC GUI

Tiger14n's RVC GUI is a standalone desktop interface for converting audio files. It can import a ZIP containing the inference .pth and its matching .index when available. Its repository is archived, so use its instructions for a workflow that specifically requires this app. The upstream RVC project's similarly named Real-time GUI is a separate launcher. RVC GUI repository and setup

Applio

Applio supports RVC voice-model management, file conversion, training, and realtime. Its Desktop and Python/Gradio editions have different setup flows. The desktop docs identify NVIDIA CUDA, supported AMD configurations, and Apple MPS and explain how to check the engine status after installation. Use the Applio conversion steps for your edition.

RVC WebUI (Mainline - Original RVC)

Retrieval-based-Voice-Conversion-WebUI is the upstream RVC project. Its WebUI handles training and file inference. The project's realtime GUI has its own launcher. The main branch documents separate CUDA dependencies for newer and older NVIDIA cards, plus a CPU dependency set for AMD and Intel systems. On Windows, DirectML may be available for supported operations. Follow the RVC WebUI (Mainline - Original RVC) conversion steps for the Windows package.

Redpanda-vc

Redpanda-vc is an Applio fork whose realtime interface supports RVC, Beatrice, and Rectified Flow. It offers multiple model families, so select the RVC workflow for an RVC voice. In its browser realtime mode, the project documents assigning streams to particular GPUs and notes that Beatrice runs on the CPU. Those resource choices apply to Redpanda-vc and its selected engine. Redpanda-vc repository and supported engines

Compare apps with the same voice

  1. Choose the package for your operating system, GPU, and model format. Check whether the app supports your model's RVC generation and feature encoder.
  2. Start with the same short recording or repeat the same few sentences into your microphone. Load the same inference model and its matching index in both apps if supported.
  3. Use the same pitch shift and turn off optional voice effects for the first comparison. Judge clear words, stable pitch, and natural pauses before adjusting the sound.
  4. For live use, run the game, call, or streaming app you normally use and record the routed output for at least a minute. Listen for gaps, hard cuts, and delayed audio before reducing the buffer.

Replay

Official website · Internet Archive

Replay is no longer supported following the closure of Weights.gg. The official Replay page may go offline at any time. The Internet Archive hosts historical Replay 8.7.0 installers. Replay is not recommended for new setups. With Weights shut down, the archived installer will likely fail to download required files, so setup may not complete.
