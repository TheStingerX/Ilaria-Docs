# Step-by-step guides by app

Pick the exact app and edition you intend to use. The setup and device names differ even when two programs can load the same RVC model. Each guide begins with a first test you can repeat, then describes settings, routing or export and common failures.

| If you want to… | Start here |
| --- | --- |
| Convert a microphone on Windows with a compatible NVIDIA GPU | [Install Vonovox](vonovox/installation.md), then [route and tune it](vonovox/live-audio.md). |
| Convert files, train voices, generate speech or set up live conversion in Applio | [Install Applio](applio/installation.md) and choose the guide for your next step. |
| Use the upstream WebUI | [Get started with Mainline RVC](mainline/installation.md). |
| Configure a live voice with w-okada VCClient | [Choose and install a VCClient build](okada/installation.md), then [test and route your mic](okada/live-audio.md). |
| Use the TG Developed Fork | [Install TGR](tgr/installation.md) for your hardware and [set up live audio](tgr/live-audio.md). |
| Convert a file in the archived Tiger14n app | [Install and convert with RVC GUI](rvc-gui/file-conversion.md). |
| Test Redpanda-vc with RVC | [Set up Redpanda-vc](redpanda/first-run.md), then [test its desktop or browser realtime path](redpanda/live-audio.md). |

Use one short, dry recording or the same spoken phrase for your first tests. Verify that you selected the intended model and device, and save a clean baseline before adding effects or lowering buffers.
