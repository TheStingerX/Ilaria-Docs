# Replay · Existing projects and training

If you already have a working copy, keep it and back up your original audio, exported conversions and any model files you can access. Replay historically offered file conversion and model training. For a first check, use a short recording and a voice you already have locally. If training or downloads depend on a service that no longer responds, move your source recordings and available inference files to a maintained app.
