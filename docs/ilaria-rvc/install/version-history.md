# Version history and release differences

[Download Ilaria RVC 2.4.7 for Windows (ZIP)](https://huggingface.co/TheStinger/Ilaria_RVC/resolve/main/releases/2.4.7/ILARIA_RVC-2.4.7.zip?download=true)

## Which version does this documentation describe?

The latest Windows release is **2.5.1**. Check your installed version under **Other → Update Ilaria RVC**. Use **All changes so far** there to browse the release-by-release notes even offline.

## All releases

| Release | Highlights |
| --- | --- |
| [2.5.1](https://huggingface.co/TheStinger/Ilaria_RVC/blob/main/releases/2.5.1/RELEASE-NOTES.md) | Adds ONNX export for pitch-guided RVC HiFi-GAN models, exact restoration to `.pth` from ONNX files made by Ilaria RVC, an installed-model selector and 49 pretrained entries. Some entries are download-only and include compatibility notes. The full Windows package is 2.4.7. To update from 2.4.2–2.5.0, use **Other → Update Ilaria RVC → Check for updates → Download and restart**. The update ZIP excludes the runtime and model weights. [Windows update ZIP](https://huggingface.co/TheStinger/Ilaria_RVC/resolve/main/releases/2.5.1/ILARIA_RVC-update-2.5.1.zip?download=true) [ONNX conversion guide](../manage/onnx-converter.md) |
| [2.5.0](https://github.com/TheStingerX/Ilaria-RVC/releases/tag/v2.5.0) | RefineGAN training and inference support 32, 40 and 44.1 kHz with RVC v2 and Pitch Guidance. The app automatically generates the 44.1 kHz mute waveform. Choose **None** to train from scratch if a pretrained pair uses a different architecture, including the tested KLM 5 (40 kHz) and VCTK (44.1 kHz) pairs. From 2.4.2 through 2.4.8, use **Other → Update Ilaria RVC → Check for updates → Download and restart**. The full Windows installer is 2.4.7. The 2.5.0 update ZIP excludes the runtime and model weights. |
| [2.4.8](https://github.com/TheStingerX/Ilaria-RVC/releases/tag/v2.4.8) | Ilaria RVC 2.4.8 adds Legacy Core V1.5 at 32 and 40 kHz to the downloader. All four Legacy Core options use `HiFi-GAN` + `ContentVec`. From 2.4.2–2.4.7, use **Other → Update Ilaria RVC → Check for updates → Download and restart**. The update ZIP excludes the Windows runtime and model weights. |
| [2.4.7](https://huggingface.co/TheStinger/Ilaria_RVC/tree/main/releases/2.4.7) | New full Windows base package (`ILARIA_RVC-2.4.7.zip`). Restores authorized **Legacy Core 1.5 V2** and **1.6** pretrained downloads at `32 kHz`, and improves interrupted update recovery (preserving changed support files in a separate backup while restoring the previous version). From **2.4.2 through 2.4.6**, use **Other → Update Ilaria RVC → Check for updates** and choose **Download and restart**. |
| [2.4.6](https://huggingface.co/TheStinger/Ilaria_RVC/tree/main/releases/2.4.6) | Adds **KLM Vocal ContentVec** (`klm-vocal-contentvec`) as an optional download for Inference and RVC v2 Training, and adds **43 verified KLM G/D pairs** to **Recommended pretrained models** with sample rates listed (training compatibility varies by pair). From **2.4.5**, open **Other → Update Ilaria RVC → Check for updates** and choose **Download and restart**. |
| [2.4.5](https://huggingface.co/TheStinger/Ilaria_RVC/tree/main/releases/2.4.5) | Adds `.pth` ↔ `.safetensors` model weight conversion in **Other → Convert model weights**, preserving RVC metadata and adding a **Move .pth to models** button. Improves the Inference message for files missing voice configuration, and auto-installs `safetensors` on first use if needed. From **2.4.4**, open **Other → Update Ilaria RVC → Check for updates** and choose **Download and restart**. |
| [2.4.4](https://huggingface.co/TheStinger/Ilaria_RVC/tree/main/releases/2.4.4) | Removes the six Legacy Core pretrained download options from Lyery after the source files were taken down (previously downloaded weights remain available for training). Requires **2.4.2** or later. |
| [2.4.3](https://huggingface.co/TheStinger/Ilaria_RVC/tree/main/releases/2.4.3) | Adds native **BF16** mixed-precision training, automatically selected on NVIDIA RTX 30, 40 and 50 series GPUs when all selected GPUs support it (Kaggle T4 defaults to FP16). Remembers manual `FP16` and `FP32` selections, preserves existing experiment precision unless changed explicitly, updates the Training Queue and PC training advisor, and keeps feature extraction in `FP32` and the standard RVC model export format. Requires **2.4.2** first via **Other → Update Ilaria RVC**. |
| [2.4.2](https://huggingface.co/TheStinger/Ilaria_RVC/tree/main/releases/2.4.2) | Adds **RMVPE cuDNN recovery** to recover cleanly from cuDNN pitch-extraction errors during inference and preprocessing. Install **2.4.1** first, then update via **Other → Update Ilaria RVC**. |
| [2.4.1](https://huggingface.co/TheStinger/Ilaria_RVC/tree/main/releases/2.4.1) | Adds optional local Kokoro v1.0 TTS with 54 voices, including Sara and Nicola in Italian. Clarifies the requirements for each TTS engine, fixes the default RMVPE weights path and hides verbose HuBERT INFO messages while keeping warnings and errors. Install and launch 2.4.0 first. Open **Other → Update Ilaria RVC** and install **2.4.1** when it appears. |
| [2.4.0](https://github.com/TheStingerX/Ilaria-RVC/releases/tag/v2.4.0) | The Windows package moves the app and runtime into app/ and voice models to the root models/ folder. Adds Colab and Lightning AI Studio notebooks, optional embedder download guidance in Training, and Lyery’s Legacy Core V1.5v2 (32 kHz, HiFi-GAN, ContentVec). The bundled runtime repairs pip and includes pywin32. |
| [2.3.0](https://github.com/TheStingerX/Ilaria-RVC/releases/tag/v2.3.0) | RMVPE High Register adds pitch modes, detection limits and an F0 comparison plot for high singing notes. ElevenLabs joins the TTS engines. Enter your ElevenLabs API key and select a voice. Start with a short line before converting the generated speech. MRF HiFi-GAN is available for training and inference. The pretrained catalog adds 15 generator/discriminator pairs, including KLM 4.4 X1 and X2 at 40 kHz. Match the pair to your vocoder and sample rate. Portuguese HuBERT Base is an optional inference embedder. In RVC v2 Training you can upload and save a custom HuBERT embedder. The app selects it and carries its configuration into the exported model. |
| [2.2.2.1](https://github.com/TheStingerX/Ilaria-RVC/blob/main/docs/CHANGELOG.md#222) | Updater bridge that prepares the refreshed 2.2.2 installation for 2.3.0. |
| [2.2.2](https://huggingface.co/TheStinger/Ilaria_RVC/tree/main/releases/2.2.2) | Uses PyTorch’s restricted checkpoint loader for voice models, model tools, ONNX export and training weights. The refreshed Windows ZIP includes Python 3.10 and PyTorch 2.10.0 with CUDA 12.8. Older NVIDIA GPUs use the downloadable CUDA 12.6 runtime. This update also fixes PyAV decoding and WAV export and reports preprocessing progress while writing segments. The 2.2.2 Kaggle notebook installs PyTorch and TorchAudio 2.10.0 with CUDA 12.8. |
