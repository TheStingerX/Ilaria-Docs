# Dataset Checker and Audio Analyzer

## Review the original recordings

Use the **Dataset Checker** to locate possible clipping, long pauses, unreadable files and inconsistent active levels. Listen to flagged ranges before editing. Preserve intentional pauses and quiet delivery when they belong to the intended voice.

## Inspect the cause

Use the **Audio Analyzer** to compare waveform peaks, spectrum, pitch and levels. A flattened peak can indicate clipping. A persistent spectral band during silence can point to hum. Compare suspected problems on the original and the conversion before deciding which stage to change.
