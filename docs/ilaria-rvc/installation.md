# Installation and updates

## Install the Windows package

Download the supported NVIDIA build from [Hugging Face](https://huggingface.co/TheStinger/Ilaria_RVC). Extract the whole archive into a writable local folder and run `ILARIA_RVC.bat` there. The launcher and bundled runtime must stay together. If no browser tab opens, try `http://127.0.0.1:6969` on the same PC.

## Update an existing installation

Open **Other → Update Ilaria RVC**. Check the release notes, finish active jobs and back up models, datasets and experiment state before choosing **Download and restart**. Keep the launcher open during the update. If it fails, note the first error and start with `ILARIA_RVC_LOGS.bat` for a diagnostic console.
