# Ilaria RVC documentation

You can also run Ilaria RVC on Kaggle using its remote GPU. This option works even if your computer has no NVIDIA GPU. [Ilaria RVC on Kaggle](ilaria-rvc/kaggle.md)

<div class="docs-welcome">

Ilaria RVC is a Windows application for converting recordings and training voice models. Its interface opens in a browser and the conversion engine runs on your computer. The Windows package is built for NVIDIA GPUs.

[Download for Windows](https://huggingface.co/TheStinger/Ilaria_RVC) · [Browse voice demos](https://ilariarvc.shop/en/demos/) · [Read the changelog](ilaria-rvc/version-history.md)
