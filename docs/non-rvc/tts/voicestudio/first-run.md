# VoiceStudio · First synthesis

[VoiceStudio v0.5.8 · First synthesis](https://github.com/debpalash/VoiceStudio/blob/v0.5.8/README.md)

## From text to audio

1. Open the speech generation workspace.
2. Choose a voice, an installed engine and a language that the engine supports.
3. Enter one short sentence with simple punctuation and generate.
4. Listen to the start, pauses and final word. Save once you have listened to the full clip.

## Run a controlled comparison

Keep text, language and voice fixed while changing one setting. Spell out abbreviations or numbers that are read incorrectly. For a long project, test a paragraph before rendering the full script and retain the successful segments.
