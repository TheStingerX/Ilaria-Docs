# RVC models and files

An RVC model changes the vocal character of an existing recording. Start with an isolated voice recording so background audio does not interfere with the conversion.

| File | Purpose |
| --- | --- |
| `.pth` | Model checkpoint used to convert the voice. |
| `.index` | Optional retrieval index. Use the matching index supplied with the model. |

If the result sounds unnatural, try a clean input and compare with the index disabled. Adjust pitch gradually and replay the same excerpt for each comparison.
